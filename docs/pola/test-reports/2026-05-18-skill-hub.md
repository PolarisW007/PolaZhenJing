## 本地验证

```bash
.venv/bin/python -m py_compile app/skillhub.py app/__init__.py app/auth.py
```

结果：通过。

Flask test client：

- 匿名访问 `/skills/` 返回 `200`。
- 匿名页面不显示 `管理员添加`。
- 匿名页面显示平铺分类 `.category-strip`，不再渲染分类下拉 `select[name="category"]`。
- `q=pola&category=交付` 可筛出 Pola skills。
- 下载链接返回 `200 application/zip`，zip 头为 `PK`。
- 匿名 POST 管理接口跳转登录。
- admin session 可看到 GitHub 导入入口、ZIP 上传入口和 GitHub 预览接口。
- normal session POST 管理接口返回 `403`。
- `/skills/admin/github-preview` 非法 repo 地址返回 `400`，不会写入 skill 数据。

## 线上验证

```bash
curl -k -L https://aipd.me/PolaZhenjing/skills/
curl -k -L 'https://aipd.me/PolaZhenjing/skills/?q=pola&category=%E4%BA%A4%E4%BB%98'
curl -k -L https://aipd.me/PolaZhenjing/skills/pola-a2a-usage/download
```

结果：

- Skill Hub 返回 `200 text/html`。
- 搜索/分类返回 `200 text/html`。
- 公开页存在 `.category-strip`，不存在分类下拉。
- 公开页不显示 `从 GitHub 导入` 管理按钮。

- admin cookie 下 `/skills/admin/github-preview` 非法 repo 地址返回 `400`。
- `pola-a2a-usage` 下载返回 `200 application/zip`。
- zip 解压包含 `pola-a2a-usage/SKILL.md`。
- 匿名页面不显示管理员表单。
- 服务器 test client 验证 admin 可见，普通用户 POST 返回 `403`。
