# Skill Hub 架构方案

文件注释：
- 模块名称：Skill Hub 架构方案
- 功能描述：描述 Skill Hub 的 Flask 蓝图、存储、下载和管理员添加方案
- 创建日期：2026-05-18
- 作者：Codex
- 主要变更：2026-05-18 初始创建
- 依赖模块：Flask、ZipFile、urllib、已有 admin session

## 模块影响

- 新增 `app/skillhub.py`：Skill Hub 蓝图。
- 新增 `app/templates/skillhub.html`：公共列表与管理员表单。
- 更新 `app/__init__.py`：注册蓝图。
- 更新 `app/templates/base.html`：后台导航增加 Skills。
- 更新 `portal/index.html`：Skills 区块增加“更多”入口。

## 路由

- `GET /skills`：公共 Skill Hub 列表，支持 `q` 和 `category`。
- `GET /skills/<skill_id>/download`：下载 zip。
- `POST /skills/admin/upload`：管理员上传 zip。
- `POST /skills/admin/add-github`：管理员输入 GitHub repo 自动添加。

## 存储

```text
data/skillhub/
├── registry.json
└── skills/
    └── <skill-package>/
        └── SKILL.md
```

运行时也会扫描本机可用 skill 根目录：

- `/Users/wangchang/.codex/skills`
- `/Users/wangchang/.agents/skills`
- `/PolaZhenjing/data/skillhub/skills`
- `data/skillhub/skills`

## 下载

下载时根据 skill 的 `SKILL.md` 所在目录实时打包 zip，避免提前生成大量压缩包。

## 安全边界

- 管理员入口只对 `SKILL_ADMIN_USERS` 中的登录用户显示。
- GitHub 添加只接受 `github.com/owner/repo` 格式。
- Zip 解压使用安全路径检查，阻止 zip-slip。
- 下载时只打包登记的 skill 目录。
