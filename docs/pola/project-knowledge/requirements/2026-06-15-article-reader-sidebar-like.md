# 需求记录：文章阅读页右侧导航与点赞

## 原始需求

用户希望在文章详情页中，将截图里位于正文下方的“上一篇 / 下一篇 / 快速 Wiki”区域移到文章右侧，并在文章下滑时保持吸顶。同时文章需要支持宽窄屏一键切换：窄屏显示右侧区域，宽屏扩大正文并隐藏右侧区域。文章还需要提供简单点赞功能。

目标页面：

- `https://aipd.me/PolaZhenjing/articles/fde-databricks-snowflake-20260610.md`

## 目标用户

- 普通读者：阅读文章时能快速切换相关文章，并可点赞表达反馈。
- 管理员：保留已有编辑、同步发布、查看和分享工具，不被本次阅读辅助功能打断。

## 范围

- 文章详情页桌面端增加右侧 sticky 阅读侧栏。
- 右侧侧栏承载上一篇、下一篇、快速 Wiki。
- 增加宽屏/窄屏切换按钮，宽屏状态隐藏右侧侧栏并扩大正文阅读宽度。
- 增加文章点赞按钮和服务端点赞计数 API。
- 使用浏览器本地状态避免同一浏览器连续重复点赞。

## 非目标

- 不实现完整用户登录点赞、点赞列表、取消后的审计日志或通知。
- 不调整文章自动打标、分享卡片、微信 JS-SDK、后台文章管理功能。
- 不改变文章 Markdown 文件结构。

## 验收标准

- A1 文档：需求、PRD、SDD、测试报告、开发日志覆盖本次改动。
- A2 UI：桌面端文章页右侧显示 sticky 阅读侧栏；正文底部不再重复出现同一导航区域。
- A3 宽屏：点击宽屏按钮后正文变宽且右侧侧栏隐藏；再次点击恢复窄屏布局。
- A4 点赞：文章页可点击点赞，计数变化并刷新后保持服务端计数。
- A5 兼容：普通用户文章阅读、管理员工具、短链和文章列表入口保持可用。
- A6 测试：补充模板/API 测试，运行语法检查、相关 pytest 和浏览器 harness。

## 风险等级

P2。原因：新增数据库表和公开 API，会影响生产文章页主流程；但不涉及密钥、支付、后台任务或批量写文章。
