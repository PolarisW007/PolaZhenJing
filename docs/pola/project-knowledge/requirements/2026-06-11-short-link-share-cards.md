# 需求记录：文章短链与社交分享卡片

日期：2026-06-11

## 原始需求

用户指出示例文章链接 `https://aipd.me/articles/fde-databricks-snowflake-20260610.md` 过长，希望：

1. 引入短连接方案，生成短连接。
2. 分享到微信、即刻、朋友圈时不再只是裸 URL，而是尽量显示消息卡片。

## 目标

- 为公开文章提供站内短链，格式为 `https://aipd.me/s/<code>`。
- 文章页复制/分享入口默认使用短链。
- 短链页和原文章页都具备社交爬虫可读的标题、摘要、封面和 canonical 信息。
- 微信内分享继续使用现有 JS-SDK 签名接口，在可配置公众号凭据和安全域名的情况下自定义好友/朋友圈分享卡片。
- 即刻等外部平台通过 Open Graph / Twitter Card 元数据生成链接卡片。

## 非目标

- 不接入第三方短链服务。
- 不做点击统计、渠道参数统计或后台短链管理台。
- 不承诺所有平台 100% 强制显示卡片；平台客户端可能有缓存、风控或抓取策略。
- 不实现即刻官方发帖 API。

## 验收标准

- A1 文档：需求、PRD、SDD、开发日志、发布记录同步更新。
- A2 短链：任意公开文章可计算确定性短码，`/s/<code>` 可打开文章。
- A3 分享 URL：文章页复制链接、微信 JS-SDK `link`、即刻/X 分享入口优先使用短链。
- A4 卡片元数据：文章 HTML 包含 `og:title`、`og:description`、`og:image`、`og:url`、Twitter Card、Schema.org Article 和 itemprop 元数据。
- A5 微信：微信 JS-SDK 配置继续可用，好友和朋友圈分享接口读取短链、标题、摘要、封面。
- A6 即刻：文章页提供即刻分享入口，目标链接为短链；即刻抓取依赖 OG/Twitter 元数据。
- A7 兼容：旧 `/articles/<filename>.md` 链接继续可访问；短链不覆盖文章文件。
- A8 测试：最小相关 pytest、分享 harness、语法检查通过。
- A9 部署：nginx 新增 `/s/` 代理到 Flask；发布后验证短链 200、旧长链 200、卡片元数据存在。
