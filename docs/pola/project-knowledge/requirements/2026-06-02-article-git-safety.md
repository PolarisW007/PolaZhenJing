# 需求记录：文章生成流程 git 安全治理

日期：2026-06-02
需求池记录：`x3OmSzOadF`

## 用户原始需求

发布中心需求记录指出当前文章生成任务会自动 `git add -A`，容易把无关改动、密钥备份或运行产物带入提交，需要单独治理。

## 目标

- 定位所有文章生成/同步相关的自动 git add/commit 路径。
- 把 `git add -A` 改为白名单文件精确 staging。
- 在提交前阻断 `.env`、备份、数据库、token/cookie/key 命名文件和可疑密钥内容。
- 提供 dry-run 预览和测试证明，不会提交 `.env`、备份和无关 diff。

## 边界

- 本次只治理文章发布/上传同步入口，不改变文章生成、改写、图片生成和社媒发布业务逻辑。
- 不读取或输出真实密钥。
- 不清理服务器历史分叉和文章线差异，该事项已在生产收口需求中单独记录。

## 非目标

- 不替换 GitHub remote、分支策略或部署方式。
- 不自动删除现有运行产物。
- 不调整 X/微信平台发布 adapter。

## 验收标准

- A1 定位所有自动 git add/commit 路径。
- A2 改为白名单文件或 dry-run diff。
- A3 增加密钥/临时文件扫描。
- A4 用测试或脚本证明不会提交 `.env`、备份和无关 diff。
