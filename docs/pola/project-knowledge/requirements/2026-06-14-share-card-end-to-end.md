# Requirement: End-to-End Social Share Cards

## User Need

用户要求 Pola 真经文章分享到微信和即刻时，能稳定呈现带缩略图、标题、摘要的图文卡片或等价图文展示，而不是只出现裸 URL。用户已完成公众号/小程序侧认证与域名配置，不希望继续被要求手动排查后台入口。

## Scope

- 优化公开文章页的分享入口。
- 为即刻、X 和通用抓取器提供更轻量的卡片 URL。
- 为微信在 JS-SDK 分享 API 被客户端拒绝时提供可用的图文卡片备用方案。
- 保留现有 `/s/<code>` 阅读短链和文章正文阅读体验。

## Non-Goals

- 不改造微信公众号图文发布为主链路。
- 不新增小程序项目或原生 App。
- 不依赖用户继续查找不存在或已迁移的微信后台开关。

## Acceptance Criteria

- A1：文章页提供“复制卡片链接”，链接面向即刻/通用抓取器，包含 OG/Twitter 缩略图、标题、摘要。
- A2：新增轻量卡片页，HTML 首部直接输出完整卡片元数据，不加载文章正文和微信 JS-SDK。
- A3：文章页提供微信图文卡片生成/复制/下载能力，JS-SDK 失败时仍可形成可见图文缩略展示。
- A4：`/s/<code>` 阅读短链继续可访问并包含原有阅读内容、微信诊断和分享配置。
- A5：本地与云端 harness 覆盖卡片页、文章页按钮、图片响应和现有回归测试。
