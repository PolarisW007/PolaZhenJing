# Requirement: 文章浏览页普通用户与管理员体验分流

日期: 2026-06-14

## 用户原始需求

针对 `https://aipd.me/articles/fde-databricks-snowflake-20260610.md` 等文章浏览页升级:

- 截图摘要与分享区域重复,保留一个摘要区域,将功能精简后放到下方。
- 编辑、同步发布、查看以及微信、朋友圈、即刻、Twitter、LinkedIn 等分享功能只对管理员可见。
- 普通用户不需要管理后台导航,只需要 PolaUUH 统一用户中心和设置。
- 文章页增加快速 Wiki/文章链接列表,支持上一篇和下一篇,普通用户和管理员都可用。
- 统一优化普通用户和管理员的文章浏览 UI 与交互。

## 目标用户

- 普通读者/普通登录用户: 阅读文章、回文章列表、切换上一篇/下一篇、快速查看其他文章、进入统一用户中心/设置。
- 管理员: 在阅读时能编辑文章、同步发布、查看 GitHub Pages/公开页、复制/打开各平台分享能力。

## 非目标

- 不改变文章生成、上传、编辑器内容保存逻辑。
- 不改变微信 JS-SDK 签名和社交卡片 meta 的后端协议。
- 不重做文章列表的数据来源和排序规则。
- 不迁移账号体系,仅调整导航展示和页面入口心智。

## 验收标准

- A1 文档: 需求、PRD/SPEC、SDD、测试报告、开发日志记录本次范围、风险和验证。
- A2 普通文章页: 不显示编辑、同步发布、查看、微信/朋友圈、即刻、Twitter、LinkedIn、复制卡片链接、微信图文卡片、下载卡片图等管理/分享操作。
- A3 管理员文章页: 显示管理操作区,包含编辑、同步发布、查看、阅读短链、卡片链接、微信/朋友圈、即刻、Twitter、LinkedIn、下载/复制图文卡片能力。
- A4 摘要区: 页面只保留一个清晰的摘要区域,不重复展示截图摘要/分享卡片区域。
- A5 普通导航: 普通登录用户不出现 `PolaZhenjing 管理后台` 与上传/文章/发布/Skills/小王记忆/主题等后台导航;只出现文章列表、统一用户中心、设置、退出等轻导航。
- A6 文章切换: 普通用户和管理员均可看到上一篇/下一篇,并有快速文章列表切换。
- A7 回归: `/articles`、`/articles/<file>`、`/PolaZhenjing/admin/articles/<file>`、账户页和管理员后台导航均保持可访问。
- A8 Harness: 本地和线上通过 HTML 断言/浏览器检查,普通视角不泄露管理按钮,管理员视角保留操作入口。

## 风险等级

P2。涉及公开文章页、后台导航和管理员权限可见性,影响用户主阅读流程和管理入口,但不涉及数据库 schema、密钥或第三方 API 调用变更。
