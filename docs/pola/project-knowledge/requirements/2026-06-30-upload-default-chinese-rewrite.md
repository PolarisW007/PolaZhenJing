# 上传生成默认中文改写需求

## 用户原始需求

用户反馈线上文章 `software-engineering-in-the-20260629.md` 生成后没有默认翻译成中文，需要同步检查问题在哪里。

## 目标

- 上传、URL 导入、PDF/文档上传等文章生成入口在启用 AI 改写时，默认输出简体中文成稿。
- 英文素材可以保留代码、命令、API 名称、产品名、链接和必要英文专有名词，但不能整段保留英文正文。
- 现有 0% 改写语义保持不变：0% 明确表示不改写、不翻译，只做后续配图/插图流程。

## 非目标

- 本次不批量重翻译历史文章。
- 本次不改动 MiniMax 模型、图片生成、微信/社交发布链路。
- 本次不改变各风格卡片的 UI 和默认 100% 改写选择。

## 验收标准

- A1 `_call_llm_rewrite` 发给模型的用户消息明确要求输出简体中文。
- A2 通用编辑 prompt 明确要求英文或其他语言素材先忠实翻译成中文，再按改写率处理。
- A3 0% 改写仍跳过 LLM，不触发翻译。
- A4 相关单测覆盖默认中文输出契约。
- A5 不影响文章编辑页已有 AI 修改建议和改写率逻辑。

## 风险等级

P2。影响文章生成主流程内容质量，但不涉及密钥、生产配置、数据库迁移或服务可用性。
