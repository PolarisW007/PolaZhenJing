## 边界

- 本次只处理已有文章编辑页保存交互和测试覆盖。
- 不重构上传/编辑模块的整体架构。
- 不修改用户已有 `_posts/` 草稿内容。

## 验收标准

- 点击保存后按钮进入禁用态并显示“正在保存/AI 调整”状态。
- 表单提交仍向后端发送 canonical `body` 和 `save_mode`。
- Playwright harness 创建临时文章、点击保存、确认写回后自动清理。
- 本地单测、语法检查和 Playwright harness 通过。
