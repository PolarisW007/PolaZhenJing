# PRD：Admin 工作台与洞察选题池

## 1. 产品目标

把 PolaZhenjing 后台从“上传页即入口”升级为“内容运营工作台”，让管理员进入后台后先看到关键模块、状态和下一步动作。

## 2. 用户角色

- 管理员：可进入工作台、管理文章、导入选题、修改选题状态、进入小王记忆和 Skills 管理。
- 普通用户：继续使用公共文章页和 PolaUUH 用户中心，不暴露 Admin 工作台。

## 3. 页面

### 3.1 工作台 `/admin/workbench`

模块卡片：

- 文章管理：文章列表、上传生成、同步发布。
- 洞察选题：每日选题、状态筛选、导入上传。
- 小王记忆：记忆状态、待确认建议、记忆工作台。
- Skills 管理：Skill Hub、导入与管理入口。
- 项目简介及管理：项目入口、主题、用户与权限、当前说明。

首页展示：

- 文章数量、选题数量、待处理选题数、Skill 数量。
- 今日选题的前几条，便于直接导入。

### 3.2 洞察选题池 `/admin/insights/topics`

核心字段：

- 日期、标题、洞察角度、摘要、标签、来源、状态、更新时间。

交互：

- 按状态筛选。
- 每条选题可修改状态。
- 一键导入上传：生成 Markdown 洞察消息并跳转上传页。

### 3.3 上传页预填

从选题导入时：

- 默认进入“粘贴内容”。
- 默认切到 Markdown 源码模式。
- 预填标题、标签、描述和正文。
- 正文包含“洞察选题”“写作角度”“关键摘要”“参考来源”等结构。

## 4. 异常与空态

- 选题数据文件缺失时，使用内置种子选题初始化。
- 选题列表为空时，引导刷新线上选题。
- 状态非法时拒绝写入并提示错误。

## 5. 兼容要求

- 不影响既有 `/admin/upload` 手动上传、粘贴、URL 抓取能力。
- 不改变生成文章、风格选择、配图、AI 改写率流程。
- 不改变普通用户文章浏览体验。

## 6. 验收

- A1 管理员访问 `/admin/workbench` 能看到核心功能模块入口。
- A2 管理员访问 `/admin/insights/topics` 能看到每日选题列表和状态筛选。
- A3 点击选题导入后跳转 `/admin/upload?insight_topic=<id>`，上传页以 Markdown 模式预填洞察消息。
- A4 状态打标能持久化到本地 JSON。
- A5 普通未登录用户不能进入后台工作台和选题池。
- A6 工作台和选题页不展示钉钉底料入口，来源说明聚焦 PolaNews 与公开线上信号。
