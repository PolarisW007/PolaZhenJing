# X 手动发布模式 PRD

- 日期：2026-06-02
- 关联需求：X 手动发布模式

## 用户流程

1. 管理员进入发布中心。
2. 选择一篇文章进入同步发布详情页。
3. 在 X 卡片中查看系统生成的文案、来源链接、封面提示和发布 checklist。
4. 点击“生成发布包”，系统记录一条 `package_created` 发布记录。
5. 管理员复制文案并打开 X。
6. 手动发布后，把 X 链接粘贴回页面。
7. 系统记录 `published_manual` 和外部链接。

## 页面行为

### X 卡片

- 标题：`X`
- 状态：显示最新发布记录状态，默认 `未处理`。
- 主操作：`生成发布包`
- 辅助操作：`打开后台`
- 发布包字段：
  - 标题
  - 摘要
  - 正文：不超过 280 字的 X 文案
  - 标签
  - 封面
  - checklist
- 有发布记录时显示链接回填输入框。

## 状态

- `未处理`：尚未创建 X 发布包。
- `package_created`：已生成 X 手动发布包。
- `published_manual`：已回填手动发布链接。

## 异常和空态

- 文章不存在：沿用现有文章不存在提示。
- 文案为空：根据标题、摘要和链接生成，若全部为空则测试视为异常。
- 无封面：发布包封面字段为空，不阻塞生成。
- 无 token：不再作为异常或阻塞。

## 权限

- 仅管理员可进入发布中心和生成发布包。
- 链接回填继续沿用管理员发布中心权限。
