# PRD: End-to-End Share Card Experience

## User Flow

1. 用户打开文章详情页。
2. 页面顶部显示分享操作：
   - 复制卡片链接：用于即刻、X、其他支持 OG 的平台。
   - 复制阅读短链：用于直接发给读者。
   - 复制微信图文卡片：生成一张带封面、标题、摘要、短链的图片卡，并写入剪贴板。
   - 下载卡片图：在浏览器不支持图片剪贴板时使用。
3. 用户在即刻发布时粘贴卡片链接，即刻抓取 `/c/<code>` 的 OG/Twitter 元数据。
4. 用户在微信分享时，优先使用右上角分享；如果微信客户端拒绝 JS-SDK 分享 API，使用图文卡片图片 + 短链。

## Page Behavior

- `/s/<code>`：阅读短链，渲染完整文章，保留现有微信 JS-SDK 诊断。
- `/c/<code>`：轻量卡片页，给抓取器快速读取卡片元数据；真人打开时提供“打开文章”入口，并可自动跳转阅读短链。
- 文章页复制按钮必须有明确反馈，失败时回退到文本复制或下载。

## Platform Notes

- 即刻、X 和通用平台：以 Open Graph/Twitter Card 为主要协议。
- 微信：保留 JS-SDK 设置；同时提供图片卡备用方案，避免最终用户只看到裸 URL。
- PC 微信直接粘贴 URL 是否转卡片不作为唯一验收口径；微信图文卡片备用方案必须可见可用。

## Error And Fallback

- 剪贴板图片写入失败：自动下载图片卡。
- Canvas 图片加载失败：生成不带封面的文本卡。
- 抓取器访问未知 code：返回 404。
