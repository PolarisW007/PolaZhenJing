# Skill Hub 发布清单

文件注释：
- 模块名称：Skill Hub 发布清单
- 功能描述：记录 Skill Hub 发布范围、命令、验证与回滚方式
- 创建日期：2026-05-18
- 作者：Codex
- 主要变更：2026-05-18 初始创建
- 依赖模块：Flask、systemd、Nginx、data/skillhub

## 发布范围

- Flask 应用：
  - `app/skillhub.py`
  - `app/templates/skillhub.html`
  - `app/__init__.py`
  - `app/templates/base.html`
- 根首页：
  - `portal/index.html`
- 服务器数据：
  - `/PolaZhenjing/data/skillhub/skills/`

## 发布命令摘要

```bash
rsync -av app/skillhub.py app/__init__.py pola-server:/PolaZhenjing/app/
rsync -av app/templates/skillhub.html app/templates/base.html pola-server:/PolaZhenjing/app/templates/
rsync -av portal/ pola-server:/var/www/html/
rsync -av ~/.codex/skills/ pola-server:/PolaZhenjing/data/skillhub/skills/codex/
rsync -av ~/.agents/skills/ pola-server:/PolaZhenjing/data/skillhub/skills/agents/
ssh pola-server 'cd /PolaZhenjing && .venv/bin/python -m py_compile app/skillhub.py app/__init__.py && systemctl restart polazj'
```

2026-05-18 增量发布：

## 发布后验证

- `https://aipd.me/PolaZhenjing/skills/` 返回 `200`。
- `https://aipd.me/PolaZhenjing/skills/?q=pola&category=交付` 返回 `200`。
- `https://aipd.me/PolaZhenjing/skills/pola-a2a-usage/download` 返回 zip。
- `https://aipd.me/` 首页显示 `更多 Skills` 入口。
- `https://aipd.me/PolaZhenjing/skills/?q=pola` 公开页分类为平铺切换，无分类下拉。
- 管理员可打开 GitHub 仓库导入弹窗，预览接口和确认导入表单已上线。

## 管理员配置

环境变量：

```text
SKILL_ADMIN_USERS=admin,sirius
```

未配置时默认兼容 `admin,sirius`。

## 回滚

```bash
ssh pola-server 'cd /PolaZhenjing && git checkout -- app/__init__.py app/templates/base.html && rm -f app/skillhub.py app/templates/skillhub.html && systemctl restart polazj'
```

如需移除线上 skill 数据：

```bash
ssh pola-server 'rm -rf /PolaZhenjing/data/skillhub'
```
