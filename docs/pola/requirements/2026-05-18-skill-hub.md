文件注释：
- 模块名称：Skill Hub 需求分析
- 功能描述：记录 Skill Hub 列表、下载、搜索分类和管理员添加能力的需求
- 创建日期：2026-05-18
- 作者：Codex
- 主要变更：2026-05-18 初始创建
- 依赖模块：pola-a2a-usage、pola-agent-delivery-framework、Flask

## 需求口径

在 AIPD 首页 Skills 模块增加“更多”入口，进入 Skill Hub 列表页。Skill Hub 支持：

- 展示 skill 列表。
- 按关键字搜索。
- 按分类筛选。
- 下载单个 skill 的 zip 包。
- 管理员可上传 zip 添加 skill。
- 管理员可输入 GitHub repo 地址自动添加 skill。
- 普通用户不可见管理员添加入口。

## 验收标准

- 首页 Skills 区块有“更多”入口。
- `/skills` 页面匿名可访问。
- `/skills?q=...&category=...` 可筛选列表。
- 每个可用 skill 有下载 zip 链接。
- 未登录普通用户看不到上传和 GitHub 添加表单。
- 管理员可访问上传和 GitHub 添加 POST。
- 非管理员访问管理员 POST 返回 403 或跳转登录。
- 新增功能不影响文章、PolaRead、PolaNews、须弥山入口。

## 非目标

- 不实现完整的权限角色后台。
- 不实现在线安装到用户本机。
- 不支持任意 Git 服务，首版仅支持 `github.com/owner/repo`。

## 管理员规则

使用环境变量 `SKILL_ADMIN_USERS` 配置管理员用户名，逗号分隔。未配置时兼容 `admin` 与 `sirius`。
